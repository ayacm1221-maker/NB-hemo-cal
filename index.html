Bedside Pattern Recognition

Possible volume / preload excess
LAVI ≥1.0、LA/Ao ≥1.3 或 LVDd 高於體重預期值。
—
Possible contractility insufficiency
LVFS <25%、LVEF <50% 或 mVcfc <0.8 circ/s。
—
Possible afterload mismatch
ESWS >45 且 LVEF <50% 或 mVcfc <0.8。
—
Possible low systemic flow
SVC flow <120 mL/kg/min。
—
這些 pattern 是決策支援提示，不是診斷。請結合 GA、日齡、血壓、PDA/MR、呼吸器條件、尿量、灌流與臨床變化。
